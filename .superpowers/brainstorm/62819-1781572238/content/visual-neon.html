Note on neon green in light mode: Pure neon (#a3e635) fails contrast on white — so light mode uses a darkened olive variant (#4a6e0a) for text and a muted lime tint for surfaces, with the full neon reserved for the CTA label on dark backgrounds. Dark mode uses full neon freely with glow. If this feels too earthy in light, the alternative is to stay indigo in light mode and only switch to neon in dark.

Does neon green work? Or prefer neon only in dark mode + indigo in light?
